# Рио Радар

Календарь цен на авиабилеты Москва → Рио-де-Жанейро на декабрь 2026 — февраль 2027.
Показывает лучшую цену на каждый день у проверенных перевозчиков (Emirates, Qatar Airways,
Turkish Airlines, Etihad, Ethiopian, Аэрофлот), не больше двух пересадок, для 1 или 2 взрослых,
в режимах «туда» и «туда и обратно».

Источник цен: Aviasales Data API (Travelpayouts). Это кеш поисков пользователей Aviasales
за последние 48 часов, поэтому на часть дней данных может не быть: такие дни показаны прочерком.

## Запуск

1. Зарегистрируйтесь на [travelpayouts.com](https://www.travelpayouts.com/) и скопируйте токен
   из профиля, раздел «API token».
2. Создайте файл `.env` из шаблона и вставьте токен:

   ```bash
   cp .env.example .env
   ```

3. Установите зависимости и запустите:

   ```bash
   npm install
   ```

   ```bash
   npm start
   ```

4. Откройте http://localhost:3000

Посмотреть интерфейс без токена на выдуманных данных:

```bash
TP_TOKEN=demo npm start
```

## Настройки

Всё в `config.js`: города, месяцы периода, белый список перевозчиков, максимум пересадок,
время жизни кеша, окно длительности поездки.

## Как это устроено

- `public/` — страница без сборки: `index.html`, `style.css`, `app.js`.
- `server/app.js` — маршруты `/api/calendar`, `/api/roundtrip`, `/api/status` на Hono.
- `server/travelpayouts.js` — клиент Aviasales Data API с кешем в памяти на 30 минут.
  Если источник недоступен, отдаётся последний удачный ответ с пометкой «устарело».
- `server/offers.js` — чистые функции: нормализация билета, фильтр по белому списку
  и пересадкам, ссылка на Aviasales, цена на двоих.
- `server/demo.js` — выдуманные данные для режима `TP_TOKEN=demo`.

Цена на двоих считается как цена за одного × 2 и помечена «расчётно»: API отдаёт только
цену за одного. Ссылка «Открыть на Aviasales» открывает живую выдачу уже с нужным числом
взрослых и датами.

## Выкладка на Cloudflare Workers

```bash
cp wrangler.example.toml wrangler.toml
```

```bash
npx wrangler secret put TP_TOKEN
```

```bash
npx wrangler deploy
```

Статика из `public/` отдаётся через `[assets]`, API работает в воркере, код тот же, что локально.
